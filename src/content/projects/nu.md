Nu is a maintained, modernized continuation of the [Mu editor](https://github.com/mu-editor/mu), a
simple code editor for beginner programmers. Mu was shaped by years of feedback from teachers and
learners. Its maintainers have archived it, and Nu exists so that classrooms can keep using it
safely.

Nu is a friendly fork. It builds directly on the work of Nicholas Tollervey and the many Mu
contributors, and it remains free software under the GPLv3. It ships the modes beginners use most:
Python 3 with a built-in REPL and plotter, Pygame Zero, CircuitPython, and a visual debugger.

To keep Nu easy to maintain, the niche hardware-specific modes inherited from Mu have been removed.
There is no packaged release yet, so for now you run it from source.
